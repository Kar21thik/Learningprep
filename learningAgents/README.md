# Learning Agents

This folder tracks all learning materials, experiments, and code for:
- Agent development and implementation
- API design and testing
- System architecture
- Tools and frameworks
- Project experiments

## Structure
- `agents/` - Agent implementations and experiments
- `apis/` - API learning and Postman collections
- `architecture/` - Design docs and diagrams
- `tools/` - Tool exploration and usage
- `projects/` - Mini-projects and POCs

Each topic gets its own subfolder with:
- Code files
- Docs/notes
- Examples
- Tests (if applicable)

## Workflow
1. Learn something new → Create folder/file
2. Add code/notes/docs
3. Commit with clear message
4. Push to GitHub
